# Leave Management (Employee Portal)

## Leave Management Module

The Leave Management Module in the Employee Self-Service (ESS) portal is a centralized and automated system that allows employees to apply for, manage, and track their leave with ease. It streamlines the entire leave lifecycle — from application and approval to balance tracking and reporting — while ensuring compliance with company policies.

## Leave Application/Withdrawal

The Leave Application/Withdrawal section is an integral part of the Employee Portal, enabling employees to manage their leaves seamlessly. This interface supports applying for new leaves, viewing previously submitted applications, and withdrawing pending leave requests. The section ensures transparency, flexibility, and ease of use, offering employees all necessary details regarding their leave balances and status updates in one place.

Key Features of the Leave Application/Withdrawal Screen:

Access to real-time leave balances, including earned leaves, optional holidays, compensatory offs, and rest days.

Applying for new leaves

Viewing or withdrawing existing leave applications

Support for different leave types and configurations, such as half-day leaves and multiple entries in a single application.

Ability to view leave application status: Applied, Approved, Rejected, or Withdrawn.

Options Available

Upon navigating to the Leave Application/Withdrawal section, the user is presented with two key options:

Proceed

Show Entered Data

Proceed

Selecting "Proceed" allows the employee to apply for new leave. The screen displays the following:

**Leave Balances:**

- Optional holidays

- Compensatory offs (if applicable)

- Rest days and Sunday comp offs (if applicable)

**Leave Application Form:**

- Type of Leave: Dropdown (Leave / Optional Holiday / Holiday Comp Off / Sunday Comp Off / Rest Day)

- Date From / Date To: Select leave duration

- Session: Forenoon / Afternoon (for half-day leave)

- Leave Days: Auto-calculated or manually input

- Reason for Leave

- Status: Auto-filled as “Applied”

- Reason for Rejection/Cancellation: Relevant only in future stages

**Actions Available:**

Proceed: Initiates the leave application process

Add New Row: Apply for multiple leave periods in one submission

Delete Row: Remove unwanted entries

Save: To save the entered data

Cancel: Exit the current application screen

Refresh: Reset the form

#### 2. Show Entered Data

Selecting "Show Entered Data" allows employees to view their previously submitted leave requests and optionally withdraw any that are in the Applied state..

**Filter Options:**

Date From / Date To: Defaults to current month range; can be adjusted

Leave Type Filter: Optional (Leave, LOP, Optional Holiday, etc.)

Status Filter: Optional; can select one or more from Applied, Rejected,Approved, Withdrawn

**Key Features:**

Leave balance and leave types (same as in “Proceed”)

**List of applied leaves along with:**

- Type of leave applied

- Date range

- Status of the applied leave : Applied, Rejected,Approved, Withdrawn

- Reason for leave

Option to withdraw leave: Selecting "Withdraw" from the Status drop-down in the relevant row

**Actions Available:**

Save: To save the entered data

Cancel: Exit current view

Refresh: Reload data

New Page: Navigate back to the previous screen

A new facility has been implemented recently. That is for canceling the already approved leave applications. Employee can place the request by accessing the application history. Cancellation request placed can be withdrawn also.

## Leave Approval/Rejection

This screen is for supervisors who are authorized to approve the leave applications of team members or direct reports. All such leave applications will be listed out and the supervisor can approve/recommend/reject the applications. There is a two level approval process in place. Immediate supervisor or team lead will recommend the leave application and the manager or reporting head will approve the leave application. There is provision to reject the application in both the levels. If first and second level supervisor is the same person, leave application will be approved in the first level itself. Approved or rejected leave history can also be viewed.

## Leave Sanctioning Cancellation

Leave cancellation from team members are listed out in this screen that can be accessed by supervisors. When they approve the requests, the already approved leave application swill be canceled.
